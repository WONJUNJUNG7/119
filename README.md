# 전국 소방 취약도 분석 & 출동 네비게이션 제안

## 실행 방법

### 방법 1: 더블클릭으로 실행 (권장)
1. `start_streamlit.bat` 파일을 **더블클릭**하세요
2. 자동으로 필요한 패키지가 설치되고 브라우저가 열립니다

### 방법 2: PowerShell에서 실행
PowerShell을 사용하는 경우:
```powershell
.\start_streamlit.bat
```

### 방법 3: CMD에서 실행
CMD를 사용하는 경우:
```cmd
start_streamlit.bat
```

## 주의사항
- PowerShell에서 실행할 때는 `.\`를 앞에 붙여야 합니다 (예: `.\start_streamlit.bat`)
- 파일 탐색기에서 더블클릭하는 것이 가장 간단합니다
